# 从 Notion 迁移

要从 Notion 迁移到 Anytype，你需要：

1. 导出你的 Notion 工作区为 HTML 或 Markdown 格式
2. 在 Anytype 中导入这些文件

### 从 Notion 导出

1. 打开你的 Notion 工作区
2. 点击左上角的 "设置与成员"
3. 点击 "设置"
4. 向下滚动到 "导出工作区内容"
5. 选择导出格式（建议选择 Markdown & CSV）
6. 点击 "导出" 并等待完成

{% hint style="info" %}
导出可能需要一些时间，具体取决于你的数据量。
{% endhint %}

### 导入到 Anytype

1. 在 Anytype 中打开命令菜单 (CMD/CTRL + K)
2. 输入 "导入"
3. 选择 "从 Notion 导入"
4. 选择你的导出文件
5. 等待导入完成

### 导入后会发生什么？

* 页面会转换为 Anytype 对象
* 数据库会转换为集合
* 标签会被保留
* 文件和图片会被导入
* 页面层级结构会被保留

### 已知限制

* 评论不会被导入
* 协作者权限不会被保留
* 某些 Notion 特定的功能可能无法完全转换
* 链接到其他 Notion 页面的链接可能需要手动更新

{% hint style="warning" %}
建议在导入后检查你的重要页面，确保所有内容都正确迁移。
{% endhint %}

### 常见问题

**问：数据库会如何转换？**
答：Notion 数据库会转换为 Anytype 集合，属性会转换为关系。某些特定的数据库视图可能需要重新配置。

**问：我可以选择性导入吗？**
答：是的，你可以选择只导出和导入特定的页面或数据库。

**问：导入需要多长时间？**
答：这取决于你的数据量。小型工作区可能只需要几分钟，而大型工作区可能需要更长时间。

**问：如果导入失败了怎么办？**
答：尝试分批导入数据，每次导入较小的数据集。如果问题仍然存在，请联系我们的支持团队。
