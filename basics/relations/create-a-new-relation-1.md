# 创建新关系

[anytype-library](../anytype-library/ "mention") 是管理、搜索和创建新关系的核心位置。

### 从“所有对象”创建关系

打开 [anytype-library](../anytype-library/ "mention") 小部件，然后导航到 **关系（Relations）** 标签页。接着，只需点击 `新建（New）` 按钮即可创建新关系。

在这里，您可以为新关系选择名称和类型。

### 从对象编辑器创建关系

要即时创建新关系，您可以按照 [#添加和管理关系](create-a-new-relation.md#adding-and-managing-relations "mention") 的说明操作，并以与关系库中的搜索栏相同的方式使用关系选择菜单。该关系将自动添加到您的关系库中，同时您可以继续编辑当前对象。

您从对象编辑器创建的任何关系都可以通过上述步骤在关系库中进行编辑。
