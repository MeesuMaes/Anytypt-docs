# 关系

### 理解关系 <a href="#understanding-relations" id="understanding-relations"></a>

关系是组织和连接 Anytype 中对象与知识的核心。在 Anytype 中，关系具有两个主要功能：

* **定义属性：** 您可以使用关系来定义某个对象的特性。
  * 例如，在 Anytype 中创建任务时，您可以添加关系，例如 _状态_：完成/未完成，或 _优先级_：低、中或高。
  * 如果我们将 Anytype 想象成一个数据库，关系就代表了每行的列标题（其中列 A 代表对象名称，每行代表一个对象）。
  * 一旦设置了属性，就可以根据您在集合视图中定义的关系对对象进行排序和筛选。

* **定义连接：** 您还可以使用关系将一个对象链接到另一个对象。
  * 回到任务的例子，您可以添加关系：_负责人（Assignee）_，并将 Anytype 中的另一个对象分配给此任务。
  * 同样地，您可以在集合视图或关系图视图中查看这些负责人作为关系。

通过这两种方式，关系不仅帮助您更好地组织信息，还使知识之间的连接更加直观和动态。
