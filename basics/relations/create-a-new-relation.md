# 添加新关系

#### 添加和管理关系 <a href="#adding-and-managing-relations" id="adding-and-managing-relations"></a>

您可以像添加编辑器中的其他块一样，为对象（Object）添加关系（Relation）：通过使用 `+` 按钮或内联的 `/` 菜单。您还可以通过对象的 **关系面板（Relations Panel）** 管理特定对象的关系：屏幕右上角出现的三角形图标。此面板显示该对象的所有关系。

**突出显示关系**

在这里，您可以添加、突出显示或修改现有的关系。突出显示关系允许您直观地优先展示与特定对象最相关的关系，因为被突出显示的关系会直接显示在标题下方。您可以通过点击关系面板中关系旁边的 ★ 图标来突出显示任何关系。

#### 关系类型 <a href="#types-of-relations" id="types-of-relations"></a>

以下是目前在 Anytype 中可用的关系类型：

* **文本（Text）**：接受文本作为输入。
* **数字（Number）**：适用于所有数字。更多格式即将推出。
* **日期（Date）**：日期，可选的时间信息。
* **状态（Status）**：分类关系，您可以定义一个选项列表供选择，例如 X、Y 或 Z。
* **标签（Tag）**：一种无限制的字符串类型，仅包含一个字符串。
* **电子邮件/电话/URL**：用于 URL、电子邮件和电话号码的特殊格式。
* **复选框（Checkbox）**：布尔值、字符串或指向对象的链接。
* **媒体（Media）**：音频、视频或图片，您可以查看、播放或下载。
* **对象（Object）**：指向特定对象的引用，例如一个人、任务或文档。
