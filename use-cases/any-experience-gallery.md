# 🖼️ ANY 体验库

### 从体验库安装体验

为了让浏览和安装体验变得更加简单，Anytype 现在新增了体验库功能。打开您的空间导航标签，点击“库”，然后安装您选择的体验。

或者，您也可以通过点击以下链接在浏览器中打开体验库：

### 创建并与他人分享

我们很高兴向您介绍 [Gallery](https://gallery.any.coop/)——一种与其他用户分享您的 ANY 体验的方法。我们相信您一定为自己的知识管理、任务跟踪、学习方法等设置感到自豪。这是一个与社区分享您的设置的机会，让他们也能充分利用 Anytype！

要创建并分享您自己的 ANY 体验，请按照以下步骤操作（您需要一个 Github 账户）：

1. 创建一个新空间，其中仅包含您想要分享的类型、关系、小部件、模板和对象。这将避免从您的主空间中意外分享敏感数据。请注意：此新空间的名称和图标将显示给所有安装您 ANY 体验的用户。
2. 当空间准备好后，以 Any-Block JSON 格式导出它。点击左上角的空间名称，点击“导出空间”，选择“Any-Block”选项并设置以下导出设置：
   1. 文件格式 – JSON，
   2. 打开“Zip 压缩包”
   3. 打开“包含文件”
3. 制作一张或多张展示您 ANY 体验重要功能的截图。将这些截图保存为 .png 格式。
4. 现在，创建了导出的空间和截图后，您可以将它们上传到体验库。在 [Gallery](https://gallery.any.coop/) 中探索现有的体验，获取命名、描述和截图的示例。然后，请登录 Github，点击[此链接](https://github.com/anyproto/gallery/issues/new?assignees=\&labels=experience\&projects=\&template=new\_experience.yml)创建请求并填写表单：
   1. 给请求起一个标题
   2. 将导出的 Zip 压缩包拖放到“体验”字段
   3. 在“标题”字段中为您的体验写一个标题；它应该是唯一的、简短的，并用英文书写
   4. 将 .png 截图拖放到“截图”字段
   5. 在“描述”字段中为体验写一段英文描述
   6. 在“类别”字段中选择一个或多个适合您体验的类别
   7. 如果体验中的内容不是英文，请在“语言”字段中选择语言
   8. 目前，所有体验均以 MIT 许可证发布；请在“条款”部分确认您同意该许可证，您有权发布此类内容，并且体验中没有有害内容
   9. 准备好后，点击“提交新问题”按钮
5. Open Any 团队的成员将审核您的提交，当通过审核后，体验将发布在 [Gallery](https://gallery.any.coop)。您将被认定为我们 [Github](https://github.com/anyproto/contributors) 和 [网站](https://anytype.io/contributors) 上的贡献者。
