# 社区论坛

我们的社区论坛是一个分享想法、提出问题和与其他 Anytype 用户交流的地方。

### 加入社区

访问我们的论坛：[community.anytype.io](https://community.anytype.io)

在那里你可以：
* 阅读公告
* 参与讨论
* 分享使用技巧
* 提出功能建议
* 报告问题

### 论坛分类

论坛分为几个主要板块：

**一般讨论**
* 分享想法和反馈
* 讨论最佳实践
* 提出一般性问题

**技术支持**
* 获取帮助
* 报告错误
* 解决技术问题

**功能请求**
* 提出新功能建议
* 投票支持想法
* 跟踪功能开发进度

### 参与指南

为了维护一个友好和有帮助的社区环境：
* 发帖前先搜索相似主题
* 选择合适的板块发帖
* 提供清晰和详细的信息
* 尊重其他社区成员
* 遵守社区准则

### 获取帮助

如果你需要帮助：
1. 先使用搜索功能
2. 查看相关板块的置顶帖
3. 如果找不到答案，创建新帖子

创建新帖子时：
* 使用描述性标题
* 提供详细信息
* 说明你已尝试过的解决方案

{% hint style="info" %}
我们的社区管理员和资深用户经常在论坛上提供帮助和建议。
{% endhint %}
