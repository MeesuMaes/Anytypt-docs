# 自定义 CSS

你可以使用自定义 CSS 来个性化你的 Anytype 界面。

### 开始使用

要开始使用自定义 CSS：

1. 打开设置
2. 导航到 "外观" 部分
3. 找到 "自定义 CSS" 选项
4. 启用该功能

{% hint style="warning" %}
自定义 CSS 是一个实验性功能。使用时请谨慎，因为不当的 CSS 可能会影响应用的功能。
{% endhint %}

### CSS 示例

这里有一些你可以尝试的常见自定义：

**修改字体大小**
```css
.editor {
  font-size: 16px;
}
```

**更改文本颜色**
```css
.text-block {
  color: #333333;
}
```

**自定义背景**
```css
.page-content {
  background-color: #f5f5f5;
}
```

### 共享你的主题

你可以：
* 在社区论坛上分享你的 CSS
* 从其他用户那里获取灵感
* 讨论和改进主题

### 主题库

访问我们的主题库：[community.anytype.io/themes](https://community.anytype.io/c/customization/themes)

在那里你可以找到：
* 社区创建的主题
* 安装说明
* 主题预览

### 故障排除

如果遇到问题：
* 检查 CSS 语法
* 尝试禁用部分样式
* 重置为默认设置
* 在论坛上寻求帮助

{% hint style="info" %}
在应用大量 CSS 更改前，建议先备份你的设置。
{% endhint %}
